PAYMENTS ENGINEERING · ARCHITECTURE01

Refactoring core payment infrastructure during critical third-party API deprecations.

When Stripe deprecated key API versions and core payment methods, including the transition from credit transfers to bank transfers, our recurring billing engine faced severe disruption. I led the end-to-end migration of our payments core, redesigning domain logic and updating data models to support new provider objects without interrupting live payment processing.

I conducted thorough risk assessments, implemented backwards-compatible data structures, and coordinated cross-departmental testing with finance and dev teams. The migration successfully sustained uninterrupted recurring billing across all international markets while establishing stronger logging and error handling.

PAYMENT SYSTEMS · FINANCIAL RECOVERY02

Building automated recovery tooling to reconcile €300k+ in stuck funds.

Stripe API limitations and version edge cases caused legitimate bank transfers and rent payments to freeze in uncollected draft states, creating significant financial backlogs. Since finance could not resolve these discrepancies at scale, I investigated the root causes and built custom backend scripts to automate reconciliation by linking Notion operational databases directly to the Stripe API.

The tool audited invalid entries, updated status records, and safely recreated valid invoices while preserving required accounting date ranges and metadata links. This automation recovered over €200,000 in previously uncollectible funds, removing recurring manual overhead for finance and operations teams.

OPERATIONS AUTOMATION · HARDWARE INTEGRATION03

Automating smart lock provisioning to reduce setup times from hours to minutes.

Manually configuring smart locks for newly opened properties created severe operational bottlenecks. The multi-step setup required spreadsheet mapping, manual API calls, and back-office entries, taking up to two hours per building. I took full ownership of streamlining the process by developing custom automation scripts and a unified CLI tool that interfaced directly with the Salto API and our internal core database.

I integrated automated status checking, lock assignment validation, and hardware provisioning within a single terminal workflow. This reduced onboarding times to just a few minutes per property, allowing the operations team to handle last-minute property launches on opening day without technical delays.
